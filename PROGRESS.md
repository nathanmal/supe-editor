# Progress Log — supe-editor

Compressed history for Claude (and future-you) to reference across sessions. Entries are dated, newest first, terse — this is a state snapshot, not a changelog; `git log` is authoritative for that once this is under version control. Update whenever a session makes a meaningful change here, and prune/collapse old entries once they're no longer load-bearing context.

**Status (2026-11-08):** Working, tested. Blocks: `Callout`, `Container`. Editor modifications (`editor/` bundle via `EditorAssets`): page title prompt, header behavior (sticky / hide on scroll, header default + per-page override). `PageTemplateMode` opens pages template-locked for themes declaring `supe-blank-page-template` (supe-theme does). Responsive supports: phase 1 (server side) done, not yet on any block. 95 Unit tests + 10 Jest tests passing; `lint:js` clean; `lint:css` has a known config issue (below). Package docs: `CLAUDE.md` (package rules, theme contract, local dev on supe.test), `README.md` (features + reference table). Not under version control yet.

Now registers the Composer install path ↔ real path in `$wp_plugin_paths` (no-op when not symlinked).
